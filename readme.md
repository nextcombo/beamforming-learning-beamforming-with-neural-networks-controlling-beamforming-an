# Beamforming: Learning Beamforming with Neural Networks - Controlling Beamforming Antennas with a Neural Network

In recent years, the field of reconfigurable intelligent surfaces (RIS) in wireless communication has received significant attention due to its ability to dynamically reconfigure surfaces to change the pattern of electromagnetic radiation in real-time. In this study, we propose a novel deep learning model that innovatively inputs only the parameters of each signal or beam without the entire one-dimensional signal or its diffusion graph (two-dimensional information). This approach enhances efficiency and reduces the overall complexity of the model, significantly reducing the network size, enabling it to be implemented on low-cost devices. Additionally, to improve training effectiveness, the learning model attempts to estimate the discrete cosine transform applied to the output matrix rather than the original matrix, significantly improving accuracy. The proposed scheme was validated on a 10×10 1-bit programmable supersurface using a K=10 cross-validation method achieving near 95% accuracy.
Introduction: In recent years, technological advancements based on reconfigurable intelligent surfaces (RIS) have completely transformed the field of wireless communication. This area has become a cutting-edge technology capable of altering the way interactions occur in wireless environments. RIS consists of microelement matrices that can be electronically adjusted to modify the characteristics of the electromagnetic waves passing through them, thereby achieving signal optimization, obstacle removal, and adaptability to changing environments [1,2]. Through selective processing of wave direction, polarization, amplitude, or phase, RIS opens up broad possibilities in various applications such as coverage optimization, signal efficiency enhancement, and control over signals in multiple systems [3,4].
With the development of the field, major challenges have emerged, primarily focusing on electromagnetic beamforming and RIS optimization. One issue involves the need to generate a series of precise electromagnetic beam configurations in real-time, thus requiring advanced solutions and the integration of emerging technologies.
Currently, the focus of RIS research includes optimization problems and analytical challenges. Optimization issues involve developing joint beamforming and phase optimization algorithms that reduce complexity [5-7]. Analysis issues include evaluating the performance of RIS systems and comparing RIS with traditional relay systems. For example, Di Renzo et al. [8] used a plane distance/path loss model to analyze the similarities and differences between RIS and traditional relays. Björnson et al. [9] proposed a classic two-dimensional single-input-single-output (SISO) system model to explore the number of reflective elements. Additionally, Abdullah et al. [10] conducted an average performance analysis in mixed RIS and relay network configurations, covering various hybrid configurations. However, these studies often overlook the actual vertical positions of base stations, users, and RIS, and rarely involve numerical verification of the relationship between RIS deployment and performance enhancement. Therefore, there is an urgent need for RIS deployment analysis to provide practical guidance for its practical applications.
Programmable metasurfaces have recently been proposed, which can dynamically manipulate electromagnetic waves incident on them. This is achieved by integrating active components (such as PIN diodes) into the metasurface elements. By independently changing the state of these components, the phase of each metasurface element's reflected wave can be adjusted, creating complex spatial waveforms. This provides additional degrees of freedom for real-time control of wave propagation. The reflection phase of the elements can be quantized using binary codes. For example, a one-bit code "0/1" represents two different reflection coefficients for an element, and a two-bit code "00/01/10/11" represents four different states for an element's reflection coefficients. Based on the dynamic manipulation of electromagnetic waves by programmable metasurfaces, these surfaces allow for the adjustment of unit characteristics using digital codes, thus generating complex electromagnetic beams in both space and time domains.
The traditional method for determining the optimal code required for defining the desired beam parameters involves using nonlinear optimization algorithms such as genetic algorithms and particle swarm optimization [12]. However, these methods have high computational complexity, posing significant challenges to their real-time implementation [14].
Deep learning has provided solutions in various fields, including image and video processing. Recently, these technologies have also been applied in the field of RIS (Resonant Induced Surface) and have achieved satisfactory results. Shan et al. [18] developed a variant of the VGG model (a deep learning model used for image classification [17]) that estimates the coding scheme for a one-bit programmable metasurface from a two-dimensional input matrix representing each possible beam configuration radiation pattern; each beam direction can be represented by two angles φ and θ, as shown in Figure 1. The use of a one-dimensional signal to represent the input radiation was employed in these approaches. Within these schemes, two models were applied: forward prediction of the metasurface and reverse design of the one-dimensional signal. Similarly, Qiu et al. [21] proposed a new method (REACTIVE) that automatically estimates the metasurface structure by applying an encoder to a set of patterns obtained after encoding the input signal (S parameters). Shi et al. [22] presented a similar approach: training an encoder to obtain a simplified representation of electromagnetic signal characteristics, followed by using an artificial bee colony algorithm (an optimization heuristic algorithm) to optimize support vector machines (a classical machine learning model [23]). Despite the very interesting results achieved by previous approaches, the neural network size in each may be too large to adapt to low-cost devices. On the other hand, there might be some redundancy in the input information (hundreds of features in a one-dimensional signal or a two-dimensional graph), because in most cases, they are generated by the φ and θ values needed to estimate the metasurface's beams.
This study focuses on the development of a neural network that allows for the return of the activation patterns of the actuator elements required to generate such beam configurations through machine learning participation in the neural network. This method significantly improves the efficiency of RIS by using only the φ and θ values of each beam as inputs, through the use of deep convolutional neural networks for efficient computation of necessary element codes. The proposed method has been validated on a 1-bit programmable surface, achieving consistent results. Therefore, it underscores the immense potential of deep learning and provides promising solutions for its further application in different fields, opening up new avenues.

Conclusion Despite significant progress in reconfigurable intelligent surfaces (RIS), the actual realization of precise and real-time configuration of electromagnetic beams remains a considerable challenge.
In this field, traditional methods employ nonlinear optimization algorithms such as genetic algorithms and particle swarm optimization to determine the optimal code for defining the electromagnetic beams on a programmable surface. Although these methods have proven effective in optimization, their computational complexity poses a significant challenge for real-time implementation. Our research utilizes a specially designed convolutional neural network (CNN) to efficiently compute the code required for the actuator elements on a 1-bit programmable surface, yielding consistent and promising results. Such models are based on their ability to learn and model complex nonlinear patterns present in the data, compared to traditional methods with high computational complexity, which can efficiently solve problems.
Unlike traditional methods that employ high computational complexity nonlinear optimization algorithms, our approach integrates deep learning as an effective tool for determining the optimal code for defining the required beam parameters. Therefore, this method emphasizes efficiency and implementation speed. This focus on practical feasibility not only enhances the broad applicability of our method but also positions our research as an important step towards effectively realizing RIS in real-world scenarios.
Regarding our objective of designing neural network architectures for RIS encoding grid patterns, we analyzed a series of scenarios and observed a clear trend in the average radiation error across different contexts. However, this does not imply that any specific network architecture instance scoring higher on this metric is absolutely superior to others, as it reflects different trade-offs:
While smaller networks generally exhibit higher radiation errors, they are more suitable for deployment on resource-constrained devices due to their simplicity and faster execution speed.
This also holds true for architectures with DCT outputs: while they achieve lower radiation errors, they require non-trivial post-processing steps, which may be challenging to implement on constrained hardware.
The divide-and-conquer strategy of using two networks can yield performance gains similar to increasing channel depth, but at the cost of output quality consistency.
For DCT-based network configurations, we expect significant improvements over direct boolean output configurations. For DCT outputs, most values are close to zero, with only a few larger values. The results from DCT outputs are indeed better, but only marginally so. We speculate this is due to inherent trade-offs: for boolean outputs, the network must learn numerous parallel, highly diverse mappings between input angles and binary 0-1 values. However, since only two output values are involved, each value is relatively easy to learn without needing precise control. In contrast, although sparse, accurate reconstruction of boolean outputs after an inverse DCT step requires finer control.
In multiple qualitative experiments, we determined that when radiation errors are below 0.05, the beam quality and direction (relative to ground truth) are sufficient for accuracy.
